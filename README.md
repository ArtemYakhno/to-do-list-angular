# Angular Todo App

A simple task management app built with Angular 21

## 🚀 Demo

[Live Demo](https://artemyakhno.github.io/to-do-list-angular/)

## ✨ Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by status — All / Active / Done
- Sort tasks by priority or name
- Priority levels — Low / Medium / High

## 🛠 Tech Stack

- Angular 21
- TypeScript
- SCSS + BEM
- Angular Signals
- HttpClient + JSONPlaceholder API

## 🔧 Getting Started

### Prerequisites

- Node.js 18+
- Angular CLI

```bash
npm install -g @angular/cli
```

### Installation

```bash
git clone https://github.com/ArtemYakhno/to-do-list-angular.git
cd YOUR_REPO
npm install
```

### Run locally

```bash
ng serve
```

Open [http://localhost:4200](http://localhost:4200)

### Build

```bash
ng build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```
